## 1. 名前

**「アースキーのデジタル名刺」** — URL は `earthkey.me/card/`。
紙の名刺に刷るQRの飛び先。ページ内にQRは置かない（QRは紙側にある）。

## 2. デザインの方向性

**「深い森の中に置かれた、一枚の紙の名刺」。**

- 地の色は既存LPの Forest Palette をそのまま引き写す（新しい色を発明しない＝site_producer 工程2）
- **カード本体だけがクリーム色（`--cream` #F7F3E7）＝紙**。暗い森の地に対して、カードだけが浮く
- **反復モチーフは「カプセル」**。アースキー本人アバターの額当てに刻まれた
  「medicine capsule-shaped metal badge（AI刻印）」が出典（`EarthKey_Avatar.md`）。
  リンクボタン・区切り線・アバターの縁を、すべてカプセルの角丸で統一する。
  → 汎用のAIっぽい丸角ではなく、**本人の辞書に実在する形**を使う
- 書体は既存LPと共有する（`Zen Maru Gothic` = 見出し／`Zen Kaku Gothic New` = 本文）。
  site_producer 工程2「色で作品性、書体で作者性」に従い、**書体だけを他ページと揃える**
- アニメーションは**ページ読み込み時の1回だけ**（カードがすっと立ち上がる）。
  `prefers-reduced-motion: reduce` では出さない

**避けるもの**: 紫グラデーション、Inter/Roboto、影を重ねた立体ボタン、意味のないマイクロインタラクション。

## 3. レスポンシブ設計（🔴 スマホ最優先）

**モバイルファーストで書く。PCはスマホ版を中央に置いた拡張として扱う。**

| 項目 | 値 | 根拠 |
|---|---|---|
| カード比率 | **1.65 : 1** | 日本の実物名刺 91×55mm = 1.6545:1（ワークショップ指定） |
| カード幅 | `min(92vw, 420px)` | 片手持ちのスマホで端が切れない |
| タップ領域 | **最小 56px** | ワークショップ指定 |
| 最小文字サイズ | **14px 相当を下回らない** | 金継ぎの「極小文字」検出を先回り |
| 横スクロール | **0px**（`scrollWidth - clientWidth = 0`） | site_producer 工程5 |
| 検証幅 | **390 / 768 / 1366** | 金継ぎが測る3幅に合わせる |
| セーフエリア | `env(safe-area-inset-bottom)` | iPhone のホームインジケータ被り防止 |

**カードに載せる情報は絞る。** 8項目すべてを 1.65:1 に詰めると必ず極小文字になる。

```
┌─ カード（1.65:1・クリーム）──────────┐
│  [アバター]  アースキー                │
│   正方形     アースキーネットワーク      │
│              現役病院薬剤師 × AIクリエイター │
│              Clinical Pharmacist × AI Builder │
└────────────────────────────┘
        ↓ カードの外（縦に流す）
   ひとこと（1〜2文）
   ● Substack     56px
   ● X            56px
   ● earthkey.me  56px
   ● お問い合わせ  56px
   footer: 特商法表記
```

## 4. 「あなたならどう作るか」— 機能提案と、その採否

特典2 ステップ2（ミニマム化）を通した結果。

### 入れる（MVP）

| 機能 | 理由 |
|---|---|
| カード＋リンク4つの縦1列 | これが名刺の本体 |
| OGP / Twitter Card | 名刺URLがDMで送られる前提。カードが出ないと信用が落ちる |
| `canonical` | `/card` と `/card/` の重複を潰す |
| LPトップからの導線 | 名刺が孤島にならない |

### 入れない（後回し）

| 機能 | 見送る理由 |
|---|---|
| vCard（.vcf）ダウンロード | 「連絡先に保存」は便利だが、**メールも電話も載せない方針**なので保存する中身が薄い。連絡先方針が変わったら復活させる |
| ページ内QRコード | QRは**紙の名刺側**にある。ここに置くと自分自身を指すQRになる |
| ダークモード切替 | 地がすでに濃い森。切替の意味がない |
| 訪問カウンタ・アクセス解析 | 名刺に不要。Cookie同意の義務も背負う |
| シェアボタン | OSの共有シートで足りる |

## 5. 技術構成

- **素のHTML/CSS。ビルドなし**（既存LP全体がそうなっている）
- ファイルは `card/index.html` の**1枚**。CSSはこのファイル内に書く
  → 既存 `style.css`（1,132行）を読み込むと、名刺に不要な森の落葉アニメ等が全部乗る
- Google Fonts は既存LPと同じ2書体のみ。**必ずシステムフォントのフォールバックを書く**
  （電波の悪い会場で名刺を見せる前提。書体が来なくても読める）
- 画像は `card/profile.jpg`（正方形・本人アバター・400×400・JPEG q92・30KB）1点のみ。Xの原本は `card/profile-original.jpg` に無改変で保全
- Cloudflare Workers の `assets.directory = "./"` により、**ディレクトリを置くだけで `/card/` が配信される**。`wrangler.jsonc` の変更は不要

## 6. セキュリティ宣言（特典2 ステップ3 ／ 特典3 準拠）

| 項目 | 方針 |
|---|---|
| APIキー | **一切使わない**。コード内に秘密情報を書かない |
| フォーム | **ページ内に入力欄を置かない**。問い合わせは既存のGoogle Formsへ外部リンク |
| 外部スクリプト | **読み込まない**（Google Fontsのスタイルシートのみ） |
| 外部リンク | `rel="noopener noreferrer"` を全件に付ける（`target="_blank"` のタブナビング防止） |
| HTTPヘッダー | 既存 `_headers` の `/*` が全ページに効く（HSTS・nosniff・frame DENY・Referrer-Policy） |
| 個人情報 | **メールアドレス・電話番号・勤務先名を書かない**（CLAUDE.md 層0/層1の境界。勤務先はボルト記録でも `【勤務先】` 表記） |
| 法的表記 | 特商法ページ `/legal/tokutei.html` へフッターからリンク |

## 7. アクセシビリティ（特典3 §10）

- アバター画像に `alt`
- リンクは `<a>`（`<div onclick>` にしない）＝キーボードで辿れる
- `:focus-visible` の輪郭を明示（森の地に対してクリーム色）
- コントラスト比 4.5:1 以上（クリーム #F7F3E7 × 森 #0B291C ＝ 高コントラスト）
- `lang="ja"`
