プライバシーポリシー

EarthKey（アースキー）が運営するこのサイトと、運営者が自分用に使う投稿ツールで、どんな情報を扱うかを定めたものです。

対象

  • ウェブサイト「earthkey.me」
  • 運営者が自分の YouTube チャンネルへ動画を投稿するために使うツール「youtube-autoupload」

このサイトで扱う情報

  • このサイトでは、アクセス解析ツールや広告用の Cookie を使っていません。
  • サイトの配信を委託している事業者が、配信のためにアクセスログ（IP アドレス、閲覧日時など）を記録することがあります。
  • お問い合わせフォームは Google フォームを使っています。入力された内容は Google のプライバシーポリシーに沿って扱われ、運営者はお問い合わせへの返信のためにだけ使います。

youtube-autoupload について

youtube-autoupload は、運営者が自分の YouTube チャンネルへ動画を投稿するためだけに使うツールです。運営者以外の方が使うことは想定していません。YouTube API サービスを使っています。

  • Google アカウントで許可を受ける権限は、動画のアップロード（youtube.upload）だけです。
  • 使い道は、運営者のチャンネルへ動画を上げ、公開範囲と公開予定時刻を設定することだけです。
  • 許可によって得た認証情報は、運営者のパソコンの中にだけ保存します。外部のサーバーには送らず、第三者へ渡すこともありません。
  • Google API から受け取った情報の扱いは、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。
  • YouTube API サービスを使うことで、YouTube 利用規約と Google プライバシーポリシーが適用されます。
  • 許可はいつでも Google アカウントのサードパーティ アクセスの設定から取り消せます。

第三者への提供

法令に基づいて求められた場合を除き、扱う情報を第三者へ提供することはありません。
